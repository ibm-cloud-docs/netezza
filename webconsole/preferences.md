# Preferences overview
{: #preferences}

The *Preferences* page allows you to enable or disable your services. Each preference is displayed as a card with a brief description and configuration controls.
- OIDC
- SAML
- Auto pause
- Database assistant
- Rest catalog
- Object storage

Use the search field to quickly locate a specific preference.
